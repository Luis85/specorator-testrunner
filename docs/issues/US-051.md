# US-051 Migrate the runner to playwright-bdd

## User Story

As a **QA Engineer**, I want the `.testrunner` to execute Gherkin through the
native Playwright runner, so that traces, retries, fixtures, and reports work
without bolt-on wiring.

## Acceptance Criteria

- `bddgen` + `npx playwright test` replaces the cucumber-js invocation
- Existing `.feature` files run unmodified
- Cucumber JSON/Messages still emitted for the import pipeline
- `Repair installation` migrates a V1 `.testrunner` non-destructively and
  reports what changed
- Demo test passes post-migration
