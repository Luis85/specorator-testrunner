# US-054 Parallel execution & retries

## User Story

As a **QA Engineer**, I want configurable workers and retries, so that suite
time drops and known-transient failures don't go red.

## Acceptance Criteria

- Settings expose workers (default: Playwright default) and retries
  (default 0 locally)
- Evidence ordering remains deterministic per scenario
- Retried-then-passed results are marked distinctly (feeds [[US-058]]
  flakiness)
- Supersedes AD-6 with a new AD
