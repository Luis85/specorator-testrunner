# US-059 Failure triage view

As a **QA Engineer**, I want failures grouped by error signature across the
run, so that one root cause isn't fifty rows.

## Acceptance Criteria

- Evidence note and Test Console group failed scenarios by normalized
  error message
- Each group links scenarios, screenshots, and traces
