# US-078 Vault & chrome hygiene

## User Story

As an **Obsidian power user**, I want evidence artifacts contained and plugin
chrome minimal, so that search, graph, and sidebar stay clean.

## Acceptance Criteria

- The ribbon trim itself lands pre-V2 with the V1 release (V2 proposal §9
  Phase 0.1 — not re-planned here); this story covers the remaining hygiene
- All artifacts stay under the configured evidence/`.testrunner` folders
- Documented `.gitignore` / Obsidian-exclude guidance
- No stray files at vault root
- New V2 views (triage, readiness, step library, …) register without adding
  default ribbon icons
