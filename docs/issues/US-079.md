# US-079 Cucumber Messages + Allure/JUnit export

## User Story

As a **QA Engineer**, I want runs to emit Cucumber Messages (NDJSON) and the
runner to support Allure and JUnit reporters, so that existing report
tooling consumes our runs for free.

## Acceptance Criteria

- Report import consumes Messages (primary) with cucumber JSON fallback
- Generated CI uploads the chosen report format
- Documented Allure setup
