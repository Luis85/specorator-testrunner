# US-082 Use Case Editor

As a **Product Owner**, I want a guided Use Case Editor — structured fields
for title, description, domain, actor, preconditions, main-success-scenario
steps, postconditions, and linked Features — so that creating a well-formed
Use Case doesn't require knowing the frontmatter schema or the UC-NNN house
format.

## Acceptance Criteria

- Follows the shipped Feature Editor pattern: structured view with
  round-trip parse/serialize of frontmatter + body sections, raw-mode
  fallback when a note doesn't round-trip, and a live validation strip
  (missing title/actor, empty success scenario, broken Feature links)
- Creates notes in the existing UC-001 format so hand-written Use Cases
  open without loss
- Reuses the focus-preserving re-render foundation from the pre-V2 plan
  item 1.12 (TD-004)
