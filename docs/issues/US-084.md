# US-084 Credential storage upgrade

## User Story

As a **QA Engineer**, I want credentials in the OS keychain (Electron
`safeStorage`) instead of plaintext `data.json`, so that a synced vault never
leaks secrets.

## Acceptance Criteria

- Transparent migration with explicit user consent
- Fallback to current behavior where keychain is unavailable (documented)
- Export/repair never prints values
- Supersedes AD-9 with a new ADR
