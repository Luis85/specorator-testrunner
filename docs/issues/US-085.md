# US-085 Session/auth reuse (storageState)

As a **QA Engineer**, I want optional Playwright `storageState` support in
the generated runner (login once per run, reuse the session), so that suites
stop re-logging-in per scenario.

## Acceptance Criteria

- Template includes a documented setup-project pattern
- Storage state file is git-ignored and excluded from evidence
- Env-var transport (ADR-0014) remains the credential source
