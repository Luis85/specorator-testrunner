# US-086 Sharded CI generation

## User Story

As a **QA Engineer**, I want the generated GitHub Actions workflow to
support sharding, so that CI suite time scales with the suite instead of
serially compounding.

## Acceptance Criteria

- Optional shard matrix with blob-report merge job and sensible artifact
  retention defaults
- Per-OS Playwright browser caching in the generated workflow
- The CI readiness check validates the sharded variant
