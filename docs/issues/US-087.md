# US-087 Multi-environment CI matrix

## User Story

As a **QA Engineer**, I want to run a suite against multiple named
Environments in one CI run, so that cross-environment regressions surface
together.

## Acceptance Criteria

- Workflow matrix over selected Environments
- Per-environment secrets follow the existing `E2E_*` convention
- Results import and evidence remain attributable per environment
