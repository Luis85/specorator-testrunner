# US-091 Accessibility check steps

## User Story

As a **Developer**, I want an opt-in axe-core step (e.g. *"Then the page
should have no critical accessibility violations"*), so that accessibility
checks live in the same business-readable specs as the rest of the suite —
the European Accessibility Act has been law since June 2025.

## Acceptance Criteria

- Opt-in step library using `@axe-core/playwright`; no default dependency
  added to generated runners that don't install it
- Severity threshold (minor/moderate/serious/critical) selectable per step
- Violations render in the Evidence note with rule IDs, impacted selectors,
  and links to the axe rule documentation
- Scoping supported (whole page or a CSS-selector region) so legacy areas
  can be excluded deliberately rather than silently
