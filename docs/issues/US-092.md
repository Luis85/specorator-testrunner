# US-092 API-setup steps

## User Story

As a **Developer**, I want documented setup-step templates that use
Playwright's `request` fixture to arrange test data over the API before a
UI flow, so that suites stop doing slow UI-driven data setup — the evidence
says API setup makes suites 3–4x faster.

## Acceptance Criteria

- Opt-in step/template library demonstrating `Given`-phase data setup via
  the `request` fixture
- Base URL and auth come from the active Environment using the existing
  env-var transport (ADR-0014) — no credentials in step code
- A failed setup step is reported as a setup failure, distinguishable from
  a genuine test failure in console and Evidence
- Explicitly within the API-*setup* scope only: standalone API-first testing
  remains a non-goal (proposal §5.3)
