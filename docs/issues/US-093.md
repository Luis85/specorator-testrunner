# US-093 Exploratory session notes

## User Story

As a **QA Engineer**, I want a timed exploratory-session note (charter,
timebox, observations, findings, screenshots) that joins the same
evidence/traceability graph as automated runs, so that exploratory testing
produces first-class, linkable evidence instead of living in a scratchpad.

## Acceptance Criteria

- Session template + command: charter, timebox, linked Use Case(s),
  observations, findings, attached screenshots
- Findings are promotable: to a draft scenario in the linked Use Case's
  feature (reusing the [[US-073]] draft mechanics) or to a standalone
  defect note
- Sessions appear in evidence rollups as manual testing, distinguishable
  from automated results
- Frontmatter properties follow the documented schema ([[US-076]]) so
  sessions are Bases-queryable
- Timer is a convenience, not a gate — sessions can be recorded after the
  fact
