# US-094 Bring-your-own-report import

## User Story

As a **QA Engineer**, I want to import Playwright JSON and JUnit XML reports
produced by suites that ran *outside* the Test Hub, so that evidence and
traceability still work when execution happens elsewhere (an existing repo,
a different CI, another team's pipeline).

## Acceptance Criteria

- The `ReportParser` port (pre-V2 plan §9 item 2.3) gains Playwright JSON
  and JUnit XML implementations with format auto-detection
- Imported runs are stamped as externally executed (origin) in evidence and
  history — never indistinguishable from hub-executed runs
- Results that can't be matched to a known Scenario Reference are reported
  explicitly, with guidance, instead of being dropped silently
- Evidence generation reuses the existing pipeline unchanged
