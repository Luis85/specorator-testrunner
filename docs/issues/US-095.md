# US-095 Test-management importers

## User Story

As a **QA Engineer** migrating from TestRail, Xray, or Zephyr, I want to
import their CSV/Markdown exports as vault notes, so that switching doesn't
mean retyping the team's test catalog — the research shows export pain is a
real switching trigger.

## Acceptance Criteria

- Importers for the common TestRail/Xray/Zephyr export shapes (CSV at
  minimum), mapping cases to Use Case notes or checklist items (the
  [[US-075]] on-ramp) per the user's choice
- Dry-run preview shows exactly what would be created before anything is
  written; nothing existing is overwritten
- Source fields that don't map onto the house schema are preserved verbatim
  in the created note (no silent data loss)
- Import summary note lists created/skipped items for review
