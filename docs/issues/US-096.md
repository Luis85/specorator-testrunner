# US-096 Headless traceability lint CLI

## User Story

As a **Developer**, I want a small CLI in `.testrunner` that lints the
vault's traceability graph — orphan requirements, uncovered scenarios,
broken links, a stale matrix — and exits non-zero on violations, so that CI
fails when the requirement→test chain breaks (the OpenFastTrace pattern) and
the vault stays a source of truth even outside Obsidian.

## Acceptance Criteria

- Runs headless against the vault files; no Obsidian required
- Rule definitions are shared with the in-plugin traceability matrix
  ([[US-061]]) — one source of truth, so CLI and plugin verdicts can't
  drift
- Output is human-readable plus a machine-readable format (JSON) for CI
  annotation
- Severity per rule is configurable; documented CI snippet shows the
  fail-the-build wiring
