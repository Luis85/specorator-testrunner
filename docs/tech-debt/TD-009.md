# TD-009 pipeline-generation-service.generate() exceeds complexity thresholds

> `PipelineGenerationService.generate()` is cyclomatic 30 / cognitive 29 /
> CRAP 30.6 (~226 LOC) and carries NO suppression — the one all-thresholds
> production finding not covered by any other tech-debt item.

## Current state

The CI-workflow generator (UC-020) builds the entire GitHub Actions pipeline —
jobs, steps, command-safety screening, the overwrite guard — in one method. The
2026-06-14 plugin-wide fallow review flagged it as the only high-severity `src`
complexity finding outside the known/suppressed set. It is **pre-existing**, so
the audit's new-only attribution treats it as inherited (it does not block
today), but any substantive edit to the file works around an un-suppressed,
un-tracked hot spot.

## Why deferred

Not on the critical path: CI generation is stable, and the V2 roadmap does not
reopen it until the later CI/sharding work (EPIC-020). Decomposing now is safe
but low-urgency.

## Intended direction

Extract the per-section builders (job emit, step emit, command-safety check)
into named helpers so `generate()` orchestrates rather than inlines — guarded by
the existing pipeline-generation tests. Do it when EPIC-020 next opens this
file, or sooner if it starts gating a change.

## Resolution

Resolved in the TD-009 decomposition increment (2026-06-16). The synchronous
screening gauntlet moved into a new pure module `ci-pipeline-screening.ts` as
named guards (`screenControlChars`, `screenRunnerPath`, `screenAuthKeys`,
`screenNodeVersion`, `screenCiCommands`, `screenRunShape`, `screenWorkflowPath`),
composed by `screenRequestInputs`; `generate()` now orchestrates
screen → resolve base → screen workflow path → overwrite-guard → write → publish.
`isSafeCiCommand` (consumed by ci-readiness) moved with the shape helpers.

Behaviour and failure ordering are unchanged — the existing
`pipeline-generation-service.test.ts` suite (every validation branch) stays green
with no new tests. Metrics: `generate()` cyclomatic 30 → 8, CRAP 30.6 → 8.0;
every extracted screen is ≤ cyclomatic 9 at 100% coverage. `fallow audit` reports
no findings in the changed files.
