# TD-010 test-execution-service runner complexity — defer to EPIC-013

> `execute()` carries a `fallow-ignore-next-line complexity` suppression and
> `tokenizeCommand` sits at cognitive 18 (inherited). Both live in
> `src/application/services/test-execution-service.ts`, which EPIC-013
> (Playwright-native runner) rewrites.

## Current state

`test-execution-service.ts` is the highest-churn file in `src/` (40 commits) and
coordinates the runner: argv build, command-safety, spawn, scope env
(`BDD_TAGS`/`BDD_FEATURES`), report wiring. `execute()`'s complexity is
suppressed; `tokenizeCommand` (already trimmed cog 23→18 in TD-008) remains just
over the cognitive threshold but is inherited and does not gate. Neither was
tracked by a register item until now — exactly the kind of suppression that gets
re-discovered each review.

## Why deferred

EPIC-013 replaces the V1 runner orchestration with playwright-bdd-native
execution (typed steps, `::run-scenario`, parallel, browser matrix), rewriting
much of this file. Decomposing `execute()` / `tokenizeCommand` now risks being
throwaway — the lesson TD-007 records.

## Intended direction

Fold the cleanup into the EPIC-013 runner rewrite: design the new execution path
under the thresholds and drop the `execute()` suppression as part of that work.
If EPIC-013 slips materially, revisit decomposing `execute()` in place. Until
then the suppression is accepted and now tracked here.
