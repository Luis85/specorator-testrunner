# TD-010 test-execution-service runner complexity — decompose during EPIC-013 US-053/US-054

> `execute()` carries a `fallow-ignore-next-line complexity` suppression and
> `tokenizeCommand` sits at cognitive 18 (inherited). Both live in
> `src/application/services/test-execution-service.ts`. Phase 3 already migrated
> the runner (US-051/052), so there is **no wholesale rewrite still pending** —
> the EPIC-013 increments that reopen this file (US-053, US-054) are the
> touchpoints.

## Current state

`test-execution-service.ts` is the highest-churn file in `src/` (40 commits) and
coordinates the runner: argv build, command-safety, spawn, scope env
(`BDD_TAGS`/`BDD_FEATURES`), report wiring. `execute()`'s complexity is
suppressed; `tokenizeCommand` (already trimmed cog 23→18 in TD-008) remains just
over the cognitive threshold but is inherited and does not gate. Neither was
tracked by a register item until now — exactly the kind of suppression that gets
re-discovered each review.

## Why deferred

`execute()`'s complexity is inherent runner orchestration (single-run lock,
scope resolution, run-env build, spawn, stream, result). Phase 3 (US-051/052)
already migrated the engine to playwright-bdd, so — unlike the original framing —
**no future "rewrite" will remove this for free** (the same stale-deferral trap
TD-007 carried). What *is* coming: EPIC-013's V2.0 increments reopen this file —
**US-053** (single-scenario scope) extends the scope dispatcher (lines ~640–674),
and **US-054** (parallel/retries) adds worker/retry wiring to the run-env and
generated config. Both ADD to the file, so the complexity only grows if left
alone.

## Intended direction

Decompose-as-you-extend — do not wait for a rewrite that is not planned:

1. When **US-053** adds the `scenario` case to the scope dispatcher, lift scope
   resolution into its own module and bring `execute()` under the thresholds in
   the same increment (drop its suppression then); fold `tokenizeCommand` in if
   **US-054** touches the run-env build.
2. If US-053/US-054 slip materially, treat this like [[TD-009]] — an explicit,
   scheduled decomposition, not an open-ended deferral.

Until then the `execute()` suppression is accepted and tracked here.
