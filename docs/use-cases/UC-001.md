# UC-001 Initialize Test Hub

> Initialize a fully functional Test Hub inside the current Obsidian vault.

- **Domain:** Installation
- **Primary Actor:** User
- **Scope:** Mandatory MVP
- **Owning Service:** `InitializationService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Preconditions

- Obsidian plugin installed.
- Vault opened.

## Main Success Scenario

1. User opens Test Hub.
2. User selects "Initialize Test Hub".
3. Plugin creates required folder structure.
4. Plugin creates documentation.
5. Plugin creates demo content.
6. Plugin creates default suites (Smoke, Regression).
7. Plugin creates `.testrunner`.
8. Plugin installs dependencies.
9. Plugin validates installation.
10. Dashboard opens.

## Postconditions

- Test Hub operational.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `testhub.initialization.started`
- `testrunner.installed`
- `documentation.generated`
- `testhub.initialization.completed`
