# UC-002 Validate Environment

> Verify system readiness.

- **Domain:** Installation
- **Primary Actor:** User
- **Scope:** Mandatory MVP
- **Owning Service:** `EnvironmentValidationService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects "Validate Environment".
2. Plugin checks Node.js.
3. Plugin checks package manager.
4. Plugin checks Playwright installation.
5. Plugin checks browser installation.
6. Plugin displays result.

## Postconditions

- Environment status known.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `testrunner.validated`
