# UC-003 Repair Installation

> Repair a damaged runner installation.

- **Domain:** Installation
- **Primary Actor:** User
- **Scope:** Optional MVP
- **Owning Service:** `MaintenanceService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects "Repair Installation".
2. Plugin validates installation.
3. Missing files are recreated.
4. Missing packages are installed.
5. Validation succeeds.

## Postconditions

- Installation repaired.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `testrunner.repaired`
