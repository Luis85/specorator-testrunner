# UC-005 Edit Use Case

> Maintain a Use Case.

- **Domain:** Requirements
- **Primary Actor:** Product Owner
- **Scope:** Optional MVP
- **Owning Service:** `UseCaseAggregate` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User opens Use Case.
2. User updates content.
3. Plugin updates index.

## Postconditions

- Use Case updated.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `usecase.updated`
- `usecase.status.changed`
