# UC-008 Create Test Suite

> Create a reusable suite.

- **Domain:** Suites
- **Primary Actor:** QA Engineer
- **Scope:** Mandatory MVP
- **Owning Service:** `SuiteAggregate` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects "Create Suite".
2. User enters name.
3. User selects tags.
4. Suite created.

## Postconditions

- Suite exists.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `suite.created`
