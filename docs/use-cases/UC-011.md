# UC-011 Execute Use Case

> Execute every Feature Specification belonging to a single Use Case, in declaration order (per ADR-0012).

- **Domain:** Execution
- **Primary Actor:** QA Engineer
- **Scope:** Mandatory MVP
- **Owning Service:** `TestExecutionService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User opens Use Case.
2. User selects "Run".
3. Plugin resolves `featureFiles` for the Use Case and builds a runner command targeting all of them in declaration order.
4. Plugin starts runner.
5. Results are displayed.

## Postconditions

- Use Case executed.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `testrun.requested`
- `testrun.started`
- `testrun.completed`
