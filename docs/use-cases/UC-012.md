# UC-012 Execute Feature

> Execute a complete feature.

- **Domain:** Execution
- **Primary Actor:** QA Engineer
- **Scope:** Optional MVP
- **Owning Service:** `TestExecutionService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects feature.
2. User starts execution.
3. Runner executes all scenarios.
4. Results are imported.

## Postconditions

- Feature executed.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `testrun.requested`
- `testrun.started`
- `testrun.completed`
