# UC-013 Execute Test Suite

> Execute a collection of tests.

- **Domain:** Execution
- **Primary Actor:** QA Engineer
- **Scope:** Mandatory MVP
- **Owning Service:** `TestExecutionService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects suite.
2. User starts suite execution.
3. Runner executes all matching scenarios.
4. Results imported.

## Postconditions

- Suite executed.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `testrun.requested`
- `suite.executed`
- `testrun.completed`
