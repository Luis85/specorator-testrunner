# UC-014 Execute Full Regression

> Execute all available tests.

- **Domain:** Execution
- **Primary Actor:** QA Engineer
- **Scope:** Optional MVP
- **Owning Service:** `TestExecutionService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects "Run All".
2. Runner executes all features.
3. Reports generated.
4. Dashboard updated.

## Postconditions

- Regression completed.
