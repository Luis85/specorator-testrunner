# UC-015 Monitor Test Run

> Observe execution progress.

- **Domain:** Execution
- **Primary Actor:** QA Engineer
- **Scope:** Mandatory MVP
- **Owning Service:** `TestExecutionService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User opens execution view.
2. Live output displayed.
3. Progress updated continuously.
4. Completion shown.

## Postconditions

- Run status visible.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `testrun.output.received`
