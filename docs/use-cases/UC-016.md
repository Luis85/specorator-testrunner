# UC-016 Generate Evidence

> Create auditable test evidence.

- **Domain:** Evidence
- **Primary Actor:** QA Engineer
- **Scope:** Mandatory MVP
- **Owning Service:** `EvidenceGenerationService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. Test execution completes.
2. Plugin imports reports.
3. Plugin creates evidence document.
4. Evidence linked to Use Case.

## Postconditions

- Evidence available.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `report.imported`
- `evidence.generated`
- `evidence.linkedToUseCase`
