# UC-018 View Dashboard

> View project testing status.

- **Domain:** Dashboard
- **Primary Actor:** Delivery Manager
- **Scope:** Mandatory MVP
- **Owning Service:** `TraceabilityService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User opens dashboard.
2. KPIs displayed.
3. Latest runs displayed.
4. Coverage status displayed.

## Postconditions

- Status visible.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `dashboard.opened`
- `dashboard.refreshed`
- `dashboard.kpi.updated`
