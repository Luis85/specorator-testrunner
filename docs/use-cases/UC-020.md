# UC-020 Validate CI Readiness

> Verify CI compatibility.

- **Domain:** CI/CD
- **Primary Actor:** Developer
- **Scope:** Mandatory MVP
- **Owning Service:** `EnvironmentValidationService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects "Validate CI".
2. Plugin checks runner.
3. Plugin checks scripts.
4. Plugin checks reports.
5. Readiness displayed.

## Postconditions

- CI status known.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `ci.readiness.checked`
