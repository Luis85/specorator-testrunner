# UC-021 Open User Manual

> Access documentation.

- **Domain:** Documentation
- **Primary Actor:** User
- **Scope:** Mandatory MVP
- **Owning Service:** `DocumentationView` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User opens User Manual.
2. Documentation displayed.

## Postconditions

- Documentation accessible.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `documentation.opened`
