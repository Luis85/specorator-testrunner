# UC-023 Open Troubleshooting Guide

> Help users resolve issues.

- **Domain:** Documentation
- **Primary Actor:** User
- **Scope:** Optional MVP
- **Owning Service:** `DocumentationView` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User opens Troubleshooting.
2. Common problems displayed.
3. Resolution steps available.

## Postconditions

- User can self-service issues.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `documentation.opened`
