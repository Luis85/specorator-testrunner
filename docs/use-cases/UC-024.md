# UC-024 Reset Test Hub

> Restore the Test Hub to a clean state.

- **Domain:** Installation
- **Primary Actor:** Administrator
- **Scope:** Optional MVP
- **Owning Service:** `MaintenanceService` (see [Solution Design §10](../architecture/Solution%20Design.md))

## Main Success Scenario

1. User selects "Reset Test Hub".
2. User confirms action.
3. Plugin removes generated assets.
4. Plugin recreates defaults.

## Postconditions

- Clean installation available.

## Domain Events

Emitted in the order they occur during the success scenario; see the [Event Catalog](../architecture/Event%20Catalog.md) for payload shapes.

- `settings.reset`
- `testhub.initialization.started`
- `testhub.initialization.completed`
