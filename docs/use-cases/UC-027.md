# UC-027 Run a Suite across multiple browsers

> Execute a Test Suite against Chromium, Firefox, and WebKit via Playwright
> projects, with per-browser results in evidence.

- **Domain:** Execution
- **Primary Actor:** QA Engineer
- **Epic:** [[EPIC-013]] — Playwright-Native Runner
- **Stories:** [[US-055]]
- **Owning Service:** to be assigned at acceptance

## Preconditions

- Additional browsers are installed via the install flow (Chromium remains
  the only default — the <5-min demo is preserved).
- The Suite or active Environment declares target browsers.

## Main Success Scenario

1. QA Engineer starts a Suite run.
2. Plugin generates one Playwright project per declared browser.
3. The run executes across projects (workers/retries per [[US-054]]).
4. Test Console attributes output per browser.
5. Plugin imports the report; results are distinguishable per browser.
6. Evidence groups results per browser within the single run.

## Extensions

- **2a. A declared browser binary is missing:** validation fails the start
  with an actionable install hint instead of a mid-run crash.

## Postconditions

- One Test Run is recorded (ADR-0018 holds — parallelism lives inside the
  run) with per-browser result attribution in Evidence and history.

## Domain Events

The standard run/report/evidence families are reused; per-browser
attribution is payload data, finalized with the EPIC-013 ADR.

- `testrun.started` *(scope: suite, browsers: […])*
- `testrun.completed`
- `report.imported`
- `evidence.generated`
