# UC-032 Export a client-facing test report

> Export a polished, self-contained (optionally white-label) report for a
> run, suite, or date range as proof of testing.

- **Domain:** Evidence
- **Primary Actor:** Freelancer
- **Epic:** [[EPIC-015]] — Audit-Grade Evidence & Release Readiness
- **Stories:** [[US-064]]
- **Owning Service:** to be assigned at acceptance

## Preconditions

- At least one run with Evidence exists for the chosen scope.

## Main Success Scenario

1. Freelancer selects "Export report".
2. Freelancer picks the scope (run, suite, or date range) and optional
   branding fields (title, logo, footer).
3. Plugin renders a standalone HTML report: summary, scenario table,
   embedded screenshots — readable without Obsidian, printable to PDF.
4. Plugin writes the export under `Test Evidence/exports/`.
5. Freelancer sends the file to the client.

## Extensions

- **3a. Screenshots referenced by Evidence are missing** (retention swept):
  the report renders without them and says so, rather than failing.

## Postconditions

- Export exists in the vault; retention sweeps ([[US-066]]) never touch
  `exports/`.
- Redaction posture applies — secrets never reach an export.

## Domain Events

Proposed (finalized with the EPIC-015 work):

- `report.exported`
