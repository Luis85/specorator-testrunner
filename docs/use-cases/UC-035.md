# UC-035 Facilitate discovery with an Example Map

> Capture rules, examples, and open questions next to a Use Case and turn
> agreed examples into draft scenarios.

- **Domain:** Requirements
- **Primary Actor:** Product Owner (with the team in a discovery session)
- **Epic:** [[EPIC-017]] — Discovery & Non-Technical Collaboration
- **Stories:** [[US-072]], [[US-073]]
- **Owning Service:** to be assigned at acceptance

## Preconditions

- A Use Case note exists for the story under discussion.

## Main Success Scenario

1. Product Owner creates an Example Map note attached to the Use Case
   (template + command).
2. During the session the team fills Rules, Examples, and Questions.
3. Open questions surface on the Use Case detail view until resolved.
4. After the session, the Business Analyst selects "Draft scenario" on an
   agreed rule/example pair.
5. Plugin appends a `@draft`-tagged scenario to the Use Case's feature,
   linking back to the map entry; nothing existing is overwritten.
6. The team refines drafts in the Feature Editor until they formulate
   ([[UC-007]] Edit Feature Specification).

## Extensions

- **4a. The Use Case has no feature yet:** the normal generate-feature flow
  ([[UC-006]]) runs first; drafting continues into the new file.

## Postconditions

- Discovery output lives next to the requirement; every draft scenario is
  traceable to the example that motivated it — the bridge no competitor
  has.

## Domain Events

Proposed (finalized with the EPIC-017 work):

- `examplemap.created`
- `specification.updated` *(existing family — draft appended)*
